# DraftWise - Updated Feature Documentation

## Export Formats

DraftWise supports multiple export formats for your documents:

| Format | Extension | Use Case |
|--------|-----------|----------|
| **Markdown** | `.md` | Editable text with basic formatting support |
| **Plain Text** | `.txt` | Universal compatibility, maximum portability |
| **PDF** | `.pdf` | Professional sharing and printing (A4, Letter, Legal) |

### How to Export

1. Navigate to **Documents** view
2. Hover over any document's export icon (⬇️)
3. Select your preferred format from the dropdown menu
4. File downloads automatically to your device

All exports are processed locally in your browser - no data leaves your device unless you explicitly enable AI assistance.

## Accessibility

DraftWise is committed to accessibility for all users. Key features include:

### Keyboard Navigation
- **Tab**: Move between interactive elements
- **Arrow keys**: Navigate suggestions when reviewing
- **Ctrl/Cmd + Enter**: Accept current suggestion
- **Ctrl/Cmd + ↓/↑**: Next/previous suggestion
- **Escape**: Close dialogs, rewrites, or dropdowns

### Screen Reader Support
- Live region announcements for keyboard navigation feedback
- Descriptive labels for all interactive elements
- Focus indicators throughout the interface
- Skip link at top of page for quick main content access
- ARIA landmarks for semantic structure

### Visual Indicators
- High contrast focus outlines on all interactive elements
- Clear active states for navigation buttons
- Loading animations that respect reduced motion preferences

For full accessibility documentation, see the repository's accessibility guide.

## Onboarding

First-time users can experience DraftWise through our guided onboarding tour:

1. **Welcome & Privacy Promise** - Understand local-first storage benefits
2. **Document Dashboard** - Create, import, or try sample documents  
3. **Suggestion Review** - Learn the accept/dismiss workflow
4. **Keyboard Shortcuts** - Master efficient navigation without mouse
5. **Goals & Style** - Customize audience, intent, and tone settings

The tour only runs once on fresh installs. You can restart it anytime from Settings.

## Theme Options

DraftWise respects your system preference but allows manual override:

- **System** (default): Matches OS dark/light mode setting
- **Dark**: Always use dark theme regardless of system settings
- **Light**: Always use light theme regardless of system settings

Click the sun/moon icon in the top-right corner to cycle through themes.

Your preference is stored locally and persists across sessions.

## Progressive Web App Features

DraftWise works offline by design:

- ✅ All drafting functionality available offline
- ✅ Local-first storage ensures no data loss
- ✅ Automatic sync when returning online
- ✅ Installation as desktop app supported (PWA manifest)

No cloud account required - everything stays on your device.
